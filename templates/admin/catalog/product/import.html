📋 Инструкция по формату файла

Обязательные поля:

  • name / название — название товара (непустое)
  • price / цена — цена в рублях (число ≥ 0)

Необязательные поля:

  • id — если указан и товар найден, он будет обновлён; иначе создаётся новый
  • stock / остаток на складе — целое число ≥ 0 (по умолчанию 0)
  • category / категория — название категории; если не найдена — создаётся автоматически
  • is_active / активен — 1/0, true/false, да/нет (по умолчанию активен)

Пример CSV:

id;name;price;stock;category;is_active
1;Букет из роз;1500;10;Розы;1
;Букет из тюльпанов;990;5;Тюльпаны;1
42;Старый букет;2000;0;Розы;0

Пример JSON:

[
  {"id": 1, "name": "Букет из роз", "price": 1500, "stock": 10, "category": "Розы", "is_active": 1},
  {"name": "Новый букет", "price": 990, "stock": 5, "category": "Тюльпаны", "is_active": 1}
]

ℹ️ Кодировка файла: UTF-8. При создании в Excel сохраняйте как «CSV UTF-8».
